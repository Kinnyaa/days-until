# Финальная анимация один раз для посетителя

Доработай сайт «До встречи», чтобы посетитель увидел существующую финальную анимацию с самолётами и переходом к фисташковой палитре один раз, даже если впервые открыл сайт после дедлайна. Одинаково обработай окончание таймера на открытой странице и первый визит после окончания.

Запоминай показ в localStorage отдельно для действующего дедлайна. При следующих открытиях сразу показывай «Сегодня» и финальную палитру. Не запускай анимацию в скрытой вкладке или вне видимого первого экрана: отложи её до появления экрана с таймером. Перед отложенным запуском перепроверь сохранённое состояние. Не допускай повторного запуска в рамках страницы. Если хранилище недоступно, сайт должен работать без ошибок; гарантировать сохранение между визитами в этом случае нельзя.

Сохрани reduced motion: вместо движения сразу покажи конечное состояние и запомни визит. Сохрани дедлайн, анимацию цифр, фотографию, раздел «Наш путь» и оформление. Режим ?preview=finish должен оставаться повторяемой демонстрацией с задержкой 4 секунды, в том числе после дедлайна, и не записывать состояние просмотра.

Граница идентификации посетителя — текущий браузер и профиль на данном устройстве; после очистки данных или в другом браузере возможен новый показ. Автоматические тесты запускай только по отдельной команде пользователя. После изменений выполни npm run build.
