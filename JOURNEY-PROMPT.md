# Промпт для реализации дорожки

Доработай существующий сайт с таймером: под ним добавь отдельный полноэкранный раздел «Наш путь». Первый экран сохраняет таймер, фотографию с непрозрачностью 3%, шрифт Manrope и мягкие лавандовые свечения.

Разделы переключаются вертикальной прокруткой с CSS Scroll Snap, каждый занимает ровно высоту экрана. В состоянии покоя виден один раздел. При переходе показывай содержимое только активного экрана, чтобы таймер и дорожка не читались одновременно. Сохрани обычную прокрутку, клавиатурную навигацию и prefers-reduced-motion.

Нарисуй SVG-дорожку в духе настольной игры: она начинается справа и идёт налево, плавно изгибаясь вверх и вниз. На дорожке — небольшие островки-отметки. Визуальное направление минималистичное: графитовый #2F3640 и лавандовый #B9A0F0, тонкие линии, приглушённая объёмность. Используй референс как пример траектории, без копирования его персонажей, яркой палитры и оформления.

Отметки: 11 ноября 2025, далее каждое 11-е число месяца до 11 ноября 2026 включительно, затем финиш 14 ноября 2026. Всего 14 отметок. На экране не показывай годы. Рядом с каждой датой выводи «N дней назад», для будущих дат — «через N дней», для текущего московского календарного дня — «Сегодня». Корректно склоняй слово «день». Пересчитывай значения по календарным дням Europe/Moscow, включая смену дня и возврат на вкладку.

Пройденные отметки и участок пути выдели чуть ярче. Небольшой маркер показывает текущую позицию между месячными датами. Финальный островок подпиши «Встреча». Не добавляй выдуманных событий или игровых чисел.

На широком экране дорожка занимает всю ширину. На узком оставь её горизонтальной, с собственной прокруткой и начальной позицией у правого края. Даты не должны перекрываться или становиться слишком мелкими. Дай короткую подсказку о направлении прокрутки.

Через Anime.js реализуй мягкое однократное появление отметок при первом переходе к дорожке. При уменьшении движения отключи анимацию. При завершении таймера дорожка наследует мятно-сливовую палитру #B2F2D8 / #5B2A5E. Сохрани логику таймера и подготовку GitHub Pages.
